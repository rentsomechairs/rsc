# V48 – Gallery ranking and accessory previews

- Gallery categories are now ranked by historical rental activity, using the same status weighting approach as the admin equipment ranking: completed rentals count most, confirmed/in-progress rentals count next, and other order states count lightly.
- Removed the per-item Request button from every gallery card. The main gallery request link remains at the top of the page.
- Inventory accessories now appear directly under the product image.
- Hovering or keyboard-focusing an accessory name temporarily previews its saved accessory image.
- Clicking an accessory name keeps that accessory image selected until another accessory is chosen or the page is reloaded.
- Accessories without an uploaded image still show by name but do not attempt an image swap.
- Cache version bumped to rental-ux-v48 for the gallery stylesheet and scripts.
