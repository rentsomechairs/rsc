# V44 — Transparent Inventory Image Backgrounds

- Inventory and accessory uploads now preserve transparency by resizing to PNG instead of flattening to JPEG.
- Added Inventory > Image Background global builder.
- Background types: solid, linear gradient, radial gradient.
- Optional texture overlays: noise, dots, grid, linen, diagonal.
- Global color, gradient direction and texture strength controls with live preview.
- Applying a background changes only the shared display setting; it never rewrites item image files.
- Shared background renders in Admin Inventory, Quick Peek/order thumbnails, Quick Picker, and public Gallery.
- Inventory product imagery uses contain sizing so transparent product cutouts are not cropped.
