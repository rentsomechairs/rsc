# Reminder and Copy/Paste Update

- Customer tracking now uses the existing tracking URL plus a separate four-character letter/number access code.
- Existing orders receive an access code the first time their notification composer is opened; new orders receive one when created.
- Reminder composer includes default-on switches for tracking, equipment, and address.
- Reminder equipment lines now use quantity-first itemized formatting and a combined total/payment line.
- Removed the redundant equipment summary line.
- Inline order equipment edits now recalculate item subtotal, listed total, base total, and saved total immediately unless an explicit adjusted total exists.
- Sidebar Copy Pickup Address was replaced with Copy Paste.
- Copy Paste contains three pickup-address formats and user-created editable custom buttons stored in settings.copyPasteTemplates.
