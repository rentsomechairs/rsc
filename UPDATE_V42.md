# V42 — Full View-As Employee Mode

- Admin View As Employee now exposes the same employee controls instead of a read-only preview.
- Balance opens Request a Payout while viewing as an employee.
- Payout accounts can be added/removed for the viewed employee and payout requests are submitted for that employee.

- Employee order time/status controls work while viewing as that employee.
- Employee contract confirmation/actions work in View As.
- Schedule remains tied to the viewed employee.
- Admin authentication remains active underneath, so Firestore owner permissions authorize these test/admin actions.
