# V37 Calendar + Schedule Rebuild

- Orders calendar now renders each order as a continuous bar from exchange date through return date, split cleanly only at week boundaries.
- Month calendar was compacted and made responsive so it uses the available page width instead of forcing a large scrollable grid.
- Clicking a calendar order opens a read-only order details popup. Admins can choose Edit Order from the popup.
- Schedule layout rebuilt so Typical Week is full width and the date-change calendar sits underneath it, matching the intended workflow.
- Typical Week time controls were reflowed for desktop, tablet, and phone widths to prevent overlap/cutoff.
