# V47 — Inventory image presentation controls

- Fixed radial gradients to use a true 50% / 50% center.
- Added non-destructive global image placement: scale, horizontal offset, vertical offset.
- Added adjustable CSS drop shadow: enable, color, opacity, blur, X and Y offset.
- Added edge-separation halo, brightness, contrast, and saturation controls.
- All effects are presentation-only and do not alter stored transparent images.
- Treatment is shared by Admin inventory, Quick Picker, Quick Peek/order thumbnails, and public Gallery.
- Default treatment is a modest 108% scale with soft shadow and slight contrast increase.
- Cache version bumped to rental-ux-v47.
- Live preview now uses a real uploaded inventory image when available.
- Object scale range expanded to 55%–180% for difficult cutouts.
