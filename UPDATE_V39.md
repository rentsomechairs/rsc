# V39 – Schedule Change Modal

- Schedule calendar changes now open in a modal instead of expanding below the calendar.
- Added an **Add Change** button above the schedule calendar.
- A change can be applied to a continuous **date range** in one save.
- A change can also be applied to multiple **non-consecutive individual dates** in one save.
- Clicking a calendar day opens the modal with that date preselected and allows editing/removing its existing override.
- Existing Quick Peek schedule behavior continues to read the saved per-date overrides.
